**Name:** RFCReplay

**Primary tag:** Developer Tools

**One-liner:** A GenLayer workbench that binds synthetic WebSocket trace replays to an independently attested, citation-backed RFC 6455 profile.

**Description:** RFCReplay separates rule evidence from execution. A creator freezes the full official RFC 6455 hash; validators independently interpret and substantively verify the cited basis of five fixed rules. A predefined state machine then replays caller-supplied synthetic frame sequences, recording a first violation and shortest failing prefix, incomplete conversations and input errors. The frontend supports profile creation, source capture, attestation, editable traces, live read/write lifecycle and verified recovery.
